# Third-Party Notices — Sentinel-SLA v2.0.0

This document inventories every third-party component that ships with or runs beside
Sentinel-SLA, with its licence and where to obtain it. It is generated from data —
the licence sweep script reads the **installed** package metadata (`node_modules/**`),
not the version ranges in `package.json` — and should be re-run whenever dependencies
change:

```bash
node scripts/licence-sweep.mjs --json scripts/licence-sweep.json
```

Last sweep: **2026-10-08** against the v2.0.0 dependency set — 628 installed packages;
**188 in the shipped production closure** (including platform-specific optional
binaries), 439 dev-only (build/test tooling, not distributed in release artefacts).

Sentinel-SLA itself is licensed under the PolyForm Noncommercial License 1.0.0 (root `LICENSE`).
The licences below apply to the third-party components it uses and are unaffected.

## 2. The monitoring stack — AGPL components (important)

Sentinel-SLA **assembles** the monitoring estate from upstream images and never modifies
them (project policy). Their configuration files under `deploy/`
are ours; the binaries are upstream, unmodified, shipped as separate container processes
that Sentinel-SLA talks to over HTTP. Three of them are **AGPL-3.0**:

| Component | Image (pinned) | Licence | Source | Upstream |
|---|---|---|---|---|
| Grafana | `grafana/grafana:11.1.0` | **AGPL-3.0** | https://github.com/grafana/grafana/tree/v11.1.0 | https://grafana.com/oss/grafana/ |
| Loki | `grafana/loki:3.1.0` | **AGPL-3.0** | https://github.com/grafana/loki/tree/v3.1.0 | https://grafana.com/oss/loki/ |
| Promtail | `grafana/promtail:3.1.0` | **AGPL-3.0** | https://github.com/grafana/loki/tree/v3.1.0 (clients branch of the Loki repo) | https://grafana.com/oss/loki/ |

**How to get the source**: the tags above link the exact upstream source trees
corresponding to the pinned images; both projects publish full source and building
instructions (Grafana: `go build` + embedded frontend build; Loki: `go build ./cmd/loki`).
If you obtained Sentinel-SLA offline, the images inside the offline tarball are the
unmodified upstream images (`docker save` output) and their sources are obtainable from
the links above — Grafana and Loki also publish their sources via their download pages.

The AGPL-3.0 licence terms of these components apply to those components. Sentinel-SLA's
own code is a separate program: it configures, starts and queries them over documented
HTTP APIs and does not incorporate their source or object code. Provisioning happens
exclusively through our own configuration files (`deploy/grafana/provisioning/`,
`deploy/loki/loki-config.yml`, `deploy/promtail/promtail-config.yml`).

### libvips (LGPL-3.0-or-later) — the one linked-library note

`sharp@0.34.5` (used by Next.js image optimisation) dynamically loads prebuilt **libvips**
binaries (`@img/sharp-libvips-linux-x64@1.2.4`, `@img/sharp-libvips-linuxmusl-x64@1.2.4`;
the set installed depends on the host platform). libvips is LGPL-3.0-or-later: the
binaries are **not modified** by us and are dynamically loaded, per the upstream sharp
distribution model. Source: https://github.com/libvips/libvips. If you build the image
yourself from source (rather than using the prebuilt binaries), sharp documents the
`SHARP_FORCE_GLOBAL_LIBVIPS` route for linking a system libvips.

## 7. Attribution obligations (operational checklist)

1. Keep this file with every distribution of Sentinel-SLA (it ships in `docs/` inside the
   release tarball and the offline image bundle).
2. Re-run the licence sweep after **any** dependency change; CI runs the stack tests that
   pin the sweep script's presence, and dependency updates should update
   `scripts/licence-sweep.json` in the same change.
3. If a future dependency introduces a copyleft licence, stop and re-evaluate: the
   current closure is permissive by design, and the AGPL components are isolated to the
   unmodified upstream images listed in §2.
4. Never modify the AGPL container images or ship a fork under the Sentinel name — keeping
   them unmodified is as much about licence hygiene as maintainability.
